# Code Spark — منصة تدريس مادة البرمجة (Educational Platform) منصة تعليمية متكاملة واحترافية مبنية بالكامل لتدريس مادة **"البرمجة"** الأكاديمية، تجمع بين واجهة مستخدم عربية سريعة وخفيفة، وخادم FastAPI فائق الأداء، وقاعدة بيانات علائقية كاملة تدعم كل من PostgreSQL في بيئة الإنتاج وSQLite في بيئة التطوير. --- ## �� الهوية البصرية الرسمية (Official Brand Identity) تم بناء الهوية البصرية استناداً إلى الشعار الرسمي المعتمد في صور المفاهيم (Concept Art): - **الألوان الأساسية**: أزرق كهربائي وسماوي نيون متدرج (`#1E40AF` ⟶ `#00D2FF` / `#0EA5E9` / `#22D3EE`). - **رمز المنصة**: حرف "C" السداسي المشطوف مع نجمة البريق الرباعية المضيئة في وسطه ونجمة ثانوية بالأعلى. - **الخلفية**: الفضاء الداكن العميق (`#070B14` / `#0B132B` / `#0F172A`). - **أصول المتجهات SVG**: متوفرة في `frontend/assets/branding/` وتشمل: - `logo_dark.svg` (الشعار الكامل للوضع الداكن مع الكتابة العربية والإنجليزية). - `logo_light.svg` (الشعار الكامل للوضع الفاتح). - `logo_symbol.svg` (رمز الشعار بمفرده بدقة عالية). - `favicon.svg` (أيقونة الموقع المربعة المنحنية الفاخرة). - `app_icon.svg` (أيقونة التطبيق). --- ## ��️ البنية التقنية (Technology Stack) - **الواجهة الأمامية (Frontend)**: - HTML5 + CSS3 + Vanilla JavaScript (Modular ES Modules بدون أي أطر عمل ثقيلة). - معمارية تطبيق أحادي الصفحة (SPA) مع موجه مسارات دوري ذكي (Role-Aware SPA Router). - واجهة عربية أصيلة بنظام اتجاه RTL مع دعم محاذاة LTR لمحرر الأكواد. - تصميم متجاوب 100% للشاشات من الهاتف المحمول وحتى شاشات 4K. - **الخادم الخلفي (Backend)**: - Python 3.11 + FastAPI + Uvicorn + Pydantic. - فصل تام للمهام: Routers ⟶ Services ⟶ Repositories ⟶ Database Engine. - تشفير كلمات المرور بمعيار NIST SP 800-63B (PBKDF2-HMAC-SHA256 مع 100,000 تكرار). - جلسات دخول آمنة عبر JWT (HS256) مع توكنات وصول وتجديد (Access & Refresh Tokens). - **قاعدة البيانات (Database)**: - تصميم علائقي سليم ومطبع يشمل 26 جدولاً مع المفاتيح الأجنبية والقيود والفهارس. - دعم أصيل لقاعدة بيانات PostgreSQL في الإنتاج (`schema.sql`) مع دعم SQLite السريع للتطوير المحلي. - **بيئة تنفيذ الأكواد (Code Sandbox)**: - تنفيذ أكواد بايثون وجافا سكريبت في عملية فرعية معزولة (Subprocess Isolation) مع مهلة زمنية 5 ثوانٍ وحماية ضد الحلقات اللانهائية. --- ## �� مسار التسجيل والاشتراك الحاسم (Registration & Subscription Flow) تلتزم المنصة بدقة بالمتطلب الصارم: **تسجيل الحساب أولاً بدون الحاجة لكود الاشتراك**: 1. يسجل الطالب حسابه مباشرة عبر إدخال الاسم، اسم المستخدم، البريد وكلمة المرور. 2. يتم إنشاء الحساب وتسجيل الدخول التلقائي فوراً، ويصبح بإمكان الطالب تصفح المحتوى العام والمجاني. 3. يقوم الطالب بإدخال كود الاشتراك (`CS-XXXX-XXXX`) من نافذة التفعيل المخصصة في أي وقت. 4. يتحقق الخادم من صحة الكود وحالته (`ACTIVE`) ثم يُفعّله في معاملة ذرية تمنع الاستخدام المزدوج أو التضارب. 5. يُفتح كامل المحتوى المخصص للمشتركين (`SUBSCRIBERS_ONLY`) فور التفعيل مع منح نقاط خبرة ترحيبية (XP). --- ## �� حسابات التجربة والتطوير (Default Seed Accounts) -
